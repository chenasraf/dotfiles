# Grilling & interview question format

Applies whenever you interview / grill the user with design or decision questions —
the `grilling` skill, **wayfinder** decision tickets, `grill-with-docs`, `to-prd`,
or any back-and-forth where you put choices to the user. **These rules override the
grilling skill's default of "ask the whole frontier in one round."**

## Rules

1. **One question at a time.** Ask a single question, then wait for the answer
   before asking the next. Never batch multiple numbered questions into one
   message.
2. **Label the options A, B, C …** Give concrete lettered choices (the user can
   still answer with their own).
3. **Recommend one.** Name your recommended option and why, in a line.

Still work the design tree in dependency order — settled answers unblock later
questions — just surface it **one question per turn** instead of a whole round.

## Format

```
❓ **<question title>**: <body / context>

- **A** — <option>
- **B** — <option>
- **C** — <option>

➡️ **Recommend <letter>** — <one-line why>
```

Then stop and wait for the answer before the next question.
